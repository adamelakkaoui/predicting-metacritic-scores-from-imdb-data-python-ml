# Predicting Metacritic Scores from IMDb Data – Python, ML

Academic regression pipeline organized around IMDb-like movie attributes and a Metacritic target score.

![Model comparison generated by the submitted notebook](images/final_report.png)

## What the notebook actually executes

The notebook defines an IMDb scraper, but the scraping call is commented out. Its recorded execution generates **500 synthetic movies** with IMDb-like fields, then performs cleaning, feature engineering, exploratory analysis, model training, cross-validation, hyperparameter search, residual analysis, and a new-movie example.

It compares Linear Regression, Ridge, Lasso, Random Forest, and XGBoost. The submitted output reports Lasso as the selected model with test RMSE `9.8132` and R² `0.6693`. These values apply only to the deterministic synthetic generator and recorded split; they are not evidence of performance on real IMDb or Metacritic data.

## Technologies

Python, pandas, NumPy, scikit-learn, XGBoost, Beautiful Soup, Selenium, NLTK/TextBlob, Matplotlib, Seaborn, and Plotly.

The cleaned notebook has no stored outputs. Running it recreates generated datasets and figures locally. The scraper is provided as coursework code but was not executed during the verified run; review the target site's current terms and robots policy before attempting any collection.

## Available examples

The `images/` directory contains figures produced by the submitted synthetic-data run, including EDA, correlations, feature importance, residuals, and prediction comparisons.

## Limitations

No real scraped dataset is included, and the local evidence does not support the report's claim that 500 IMDb pages were scraped. Synthetic construction directly relates the target to the generated IMDb rating, so the recorded metrics should not be generalized to real films.
